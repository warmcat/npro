# Transcripts from C lws

These files are copies of the transcripts C lws' `api-test-sansio` records
and checks itself against
(`minimal-examples-lowlevel/api-tests/api-test-sansio/transcripts` in the
C tree).  `C-COMMIT` names the C commit they were taken from.
`README.lws.md` is that directory's README, which specifies the format and
the application each connection needs on lws' side.

They are behaviour, not fixtures.  Do not edit them here: refresh them all
from a C checkout with `scripts/sync-c-oracle.sh`.  A commit that changes
them names the C commit that changed them, and says why.
